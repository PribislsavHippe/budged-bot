# Подключение Google Календаря — 13 октября 2026

## Принятое решение

- Проблема: подключение графика на Android требует установки ICSx⁵ либо
  ручного добавления ссылки через веб-версию Google. Владелец хочет короткий путь.
- Пользователь: сотрудник с Android и Google Календарём.
- Сценарий: нажать существующую кнопку → открыть Google → подтвердить подписку
  → видеть смены и получать последующие изменения при обновлении подписки.
- Гипотеза: ссылка Google с параметром `cid` позволяет подключить персональный
  календарь без ручного копирования адреса и без OAuth-доступа бота к аккаунту.
- Решение: существующая кнопка на не-Apple устройствах открывает ссылку Google;
  персональный адрес готовится до нажатия. Композиция и оформление не меняются.
- Почему: ближе к желаемому пути, чем установка дополнительного приложения;
  собственное Android-приложение сейчас избыточно. Можно оставить только ручной
  путь, но он не решает задачу сокращения действий.
- Проверка: на настоящем Android открыть из Telegram, подтвердить подписку,
  проверить новую, изменённую и удалённую смены; измерить задержку обновления.

## Ограничения и восстановление

Google может потребовать вход в аккаунт. Открытие ссылки не подтверждает
подключение: миниапп не получает такого ответа. При неудаче доступны существующие
инструкция и копирование ссылки. Новые смены обновляет Google, мгновенное
обновление не обещаем. После отзыва ссылки для нового подключения требуется
подготовка нового адреса и повторное нажатие.

Подписка передаёт Google персональную ссылку и даты/время смен; денежные записи
в неё не входят. Авторизацию бота через Google не возвращаем.

Источники: [официальное ограничение мобильного приложения](https://support.google.com/calendar/answer/37100?co=GENIE.Platform%3DAndroid&hl=en),
[описание недокументированной ссылки разработчиком](https://til.simonwillison.net/ics/google-calendar-ics-subscribe-link).
Решение согласовано владельцем в чате. Работоспособность на Android ещё
не подтверждена. Существующий экран остаётся временным.

## Реализовано и технически проверено

API возвращает `google_subscribe_url` для текущей персональной подписки.
Адрес календаря закодирован одним параметром `cid`; внешний адрес Google
фиксирован, данные из заголовка Host не используются. График не отправляется
Google при подготовке ссылки — переход происходит только по нажатию.

Проверки: `tests/api_checks.py` и `tests/calendar_subscription_ui_checks.mjs`
прошли. Проверены изоляция графика пользователя, подписанная авторизация,
замена/отзыв адреса, прежний путь iPhone, синхронное открытие Google по нажатию,
повторное открытие и восстановление после отзыва. Это локальные проверки
на заглушках, не проверка сервиса Google или Telegram на настоящем Android.
Изменения не опубликованы. Миграции не нужны.
