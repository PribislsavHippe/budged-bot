# Budget Bot v2 — железобетонный учёт денег

Telegram-бот для точного учёта денег. Сделан для нерегулярного дохода
(смены, чаевые): никаких «дней зарплаты» — только реальные деньги.

## Принципы

- **Один источник правды.** Все деньги — записи в журнале `entries`.
  Баланс всегда пересчитывается из журнала, отдельно нигде не хранится.
- **Два счёта:** наличные и карта. Видно, сколько где.
- **Запись сразу, отмена одной кнопкой.** Никаких многошаговых диалогов.
- **Сверка.** Пишешь реальный остаток — бот показывает расхождение и учитывает его.
- **Без ИИ.** Разбор сообщений — детерминированные правила, покрытые тестами.

## Как пользоваться

| Пишешь | Что происходит |
|---|---|
| `чай 500` | +500 чаевые, наличные |
| `смена 2500` | +2500 подработка, наличные |
| `зп 30000` | +30000 зарплата, карта |
| `кофе 200` | −200 еда, карта |
| `такси 350 нал` | −350 транспорт, наличные |
| `кофе 200, такси 350` | несколько операций сразу |
| `наличными 3200, на карте 8100` | сверка: покажет расхождение и учтёт |
| пересланное сообщение банка о чаевых | сумма запишется сама на карту |

Кнопки: **💰 Баланс**, **📋 История**. Команды: `/undo` — отменить последнюю
запись, `/reset` — начать заново, `/help` — подсказка.

## Установка

1. Создай бота у [@BotFather](https://t.me/BotFather), возьми токен.
2. В [Supabase](https://supabase.com) создай проект, в SQL Editor выполни `schema.sql`.
   **Обновляешься со старой версии?** Вместо этого выполни `migration_v2.sql` —
   он ничего не удаляет: добавляет таблицу `entries` и флаг `onboarded`,
   старые таблицы остаются как архив.
3. `cp env.example .env`, заполни `BOT_TOKEN`, `SUPABASE_URL`, `SUPABASE_KEY`.
4. Локально: `pip install -r requirements.txt && python main.py` — запустится polling.
5. Деплой на Render: подключи репозиторий (найдёт `render.yaml`), задай те же
   переменные плюс `WEBHOOK_HOST=https://твой-сервис.onrender.com` — включится webhook.


## Структура

```
main.py          # точка входа: polling локально / webhook на Render
handlers.py      # все хендлеры и клавиатуры
parser.py        # разбор сообщений (правила, без ИИ)
db.py            # Supabase, журнал entries
schema.sql       # схема БД
tests/           # тесты парсера
legacy/          # старая версия (не используется)
```
