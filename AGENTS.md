# Правила продуктовой работы в этом репозитории

Утверждены владельцем проекта 5 октября 2026 года. Полный текст и смысл правил:
[docs/PRODUCT_PRINCIPLES.md](docs/PRODUCT_PRINCIPLES.md). Применяй их к новым
задачам в этом проекте; не считай прежний код доказательством пользы функции.

Для заметной новой функции или изменения интерфейса/поведения до production-кода:

1. Сформулируй наблюдаемую проблему, пользователя, ситуацию, текущий обходной
   путь, желаемый результат и известные свидетельства. Не выдумывай их. Если
   ответ уже есть в переписке или исследовании, используй его без повторного
   вопроса.
2. Отдели предложенное решение от проблемы. Рассмотри несколько вариантов,
   включая упрощение существующего пути и отказ от новой функции.
3. Запиши короткий сценарий: триггер → цель → действия → реакция системы →
   результат. Для сложного пути добавь основные ошибки и исключения.
4. Для UI определи иерархию информации, действия, состояния, ошибки и пустые
   состояния, а также отличия от нынешнего экрана. Для заметной перемены
   предложи макет или прототип до production-кода.
5. Зафиксируй с владельцем одну основную гипотезу и выбранное решение в форме:
   проблема / пользователь / сценарий / гипотеза / решение / почему / проверка.
   После решения переходи к реализации без повторного запроса разрешения.

В ходе работы не расширяй задачу новыми функциями автоматически. Необходимые
исправления для корректности и безопасности выбранного сценария входят в него;
остальные идеи запиши отдельно. Предпочитай меньше действий и настроек.

После реализации различай: спроектировано, реализовано, технически проверено,
опубликовано, проверено владельцем, проверено пользователями, подтверждена или
опровергнута гипотеза. Для значимых изменений предложи наблюдение за реальными
пользователями; события аналитики показывают действия, но не мотивы.

Для очевидного бага, небольшой обратимой правки и технического обслуживания
сокращай процесс. Если следующий разумный шаг — разговор или наблюдение за
пользователем, скажи об этом. Спорь с владельцем по делу, без бюрократии.
